# 创建项目

## 使用 vite 创建项目

```bash
npm create vite@latest
```

根据交互式问答创建项目

- 首次安装系统检测到本地没有安装 create-vite，提示需要安装
- 安装完成后，create-vite脚手架开始引导用户进行项目配置
- Project name: （项目名称）
- Select a framework: （选择框架）
- Select a variant: （选择变体/语言）
- Use rolldown-vite (Experimental)? （是否使用实验性的 rolldown？）

## 启动服务

```bash
# 1. 进入刚刚创建的项目目录
cd susu-website

# 2. 安装项目依赖（package.json 中声明的所有包，如 vue, vite, typescript 等）
npm install

# 3. 启动开发服务器
npm run dev
```

## 配置 src 文件夹别名

配置 src 文件夹别名 vite.config.ts

```typescript
import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
// 引入 path 模块 path 模块为 Node.js 自带的，无需安装
// 若飘红则需安装 npm i @types/node --save-dev
// TypeScript 需要知道 Node.js 内置模块（如 path, fs, process等）的类型定义。
// @types/node提供了这些核心模块的 TypeScript 类型声明。
// --save-dev 表示将安装的包保存到项目的 devDependencies（开发依赖） 中。
import path from 'path';
// https://vite.dev/config/
export default defineConfig({
  plugins: [vue()],
  // 配置 src 文件夹别名，在项目中以 @ 符号代表根路径下的 src 件夹，目的是
  // 避免在项目中出现 src 文件夹路径，方便代码的维护
  // 若不配置，则需要使用绝对路径，如：import { xxx } from '../../src/xxx.js'
  // 配置后 import { xxx } from '@/xxx.js' 即可
  resolve: {
    alias: {
      '@': path.resolve(__dirname, 'src'),
    },
  },
})
```

并在 tsconfig.app.json 中的 compilerOptions 配置 paths，该步骤主要为了使开发 ide 工具智能提示路径

这个配置文件不一定是哪个，版本不一样也不一样，自己试试吧，idea 需要重启菜不飘红

```json
{
  "extends": "@vue/tsconfig/tsconfig.dom.json",
  "compilerOptions": {
    "tsBuildInfoFile": "./node_modules/.tmp/tsconfig.app.tsbuildinfo",
    "types": ["vite/client"],
    "baseUrl": ".",   // 添加这一行，基准路径为当前目录（项目根目录）
    /* Linting */
    "strict": true,
    "noUnusedLocals": true,
    "noUnusedParameters": true,
    "erasableSyntaxOnly": true,
    "noFallthroughCasesInSwitch": true,
    "noUncheckedSideEffectImports": true,
    /* 配置 paths */
    "paths": {
      "@/*": ["src/*"]
    }
  },
  "include": ["src/**/*.ts", "src/**/*.tsx", "src/**/*.vue"]
}
```

- **`--save-dev`** 开发阶段需要的工具/包（测试框架、构建工具、类型定义等）。
- **`--save`**  项目运行时必须的包（Vue/React 框架、UI 组件库、HTTP 库等）。

| 命令                      | 效果                               |
| :------------------------ | :--------------------------------- |
| `npm i <包名>`            | 默认保存到 `dependencies`(npm v5+) |
| `npm i <包名> --save`     | 显式保存到 `dependencies`          |
| `npm i <包名> --save-dev` | 保存到 `devDependencies`           |
| `npm i <包名> -g`         | 全局安装（通常用于命令行工具）     |
