## FNN（前馈神经网络）

FNN（前馈神经网络）通常被认为是现代深度学习中最基础、最核心的神经网络模型。

```
i1 -> 隐 -> o1
i2 -> 藏 -> o2
i3 -> 层 -> o3
```

这种模型接收固定长度的向量，也输出固定长度的向量，先说它为什么不适合序列传导任务：

假设这是一个语言翻译模型，输入 “水是有毒的”，需经过下述步骤

步骤一：分词
步骤二：词向量表示
步骤三：合并词向量


在传统的机器学习中，处理像自然语言这种有序的（即拥有前后顺序，比如“我爱编程”和“编程爱我”意思完全不同）任务时，主流的序列传导模型大多基于复杂的RNN（循环神经网络）​或CNN（卷积神经网络）​理论(实际上更多是使用 RNN)。它们通常采用编码器-解码器这种架构，并在一些表现较好的模型中引入注意力增强机制来提升效果。

## RNN (循环神经网络)：

一种带有“记忆”的神经网络。它处理当前输入时，会考虑之前所有步骤的信息。因为自然语言中，后一个词的含义往往依赖于前面的词。例如，“苹果”这个词，在“吃苹果”和“苹果手机”中意思不同。RNN 试图通过记忆上文来理解这种依赖。对于很长的序列（比如长篇文章），它很难记住很久以前的信息（称为“长程依赖”问题）。

## CNN (卷积神经网络)：

更常见于图像处理，但也被用于文本。它像一个固定大小的滑动窗口，在文本上移动，每次只关注窗口内的几个相邻词（例如3个词），来提取局部特征。能高效地捕捉像“成语”、“固定搭配”这样的局部模式。

## 主流架构：编码器-解码器

这是处理“序列到序列”任务（如翻译、摘要）的经典设计模式。

编码器：

职责：像一个“理解者”。它读取整个输入序列（如一句英文），并将其压缩、概括成一个固定长度的上下文向量（可以理解为整个句子的“思想”或“语义摘要”）。
实现：通常是一个RNN，逐词读入句子，最终状态即为上下文向量。

解码器：

职责：像一个“生成者”。它从编码器得到的“上下文向量”开始，逐步生成输出序列（如对应的中文句子）。
实现：通常也是一个RNN，其初始状态被设置为那个上下文向量。

## 注意力机制

早期的编码器-解码器有个大问题：要求把所有信息塞进一个固定长度的向量里。对于长句子，这个向量就像个内存不足的缓冲区，会丢失细节。

注意力机制是什么：

它允许解码器在生成每一个输出词时，都能“回看”编码器处理输入序列时得到的所有中间状态，并动态地决定此时应该“重点关注”输入序列的哪一部分。它不再强迫模型通过一个瓶颈向量来记忆一切。

实际案例（机器翻译）：

翻译 "The animal didn't cross the street because it was too tired."中的 "it"。

没有注意力：解码器只依赖那个可能已经模糊的上下文向量，可能错误地将 "it"关联到 "street"。

有注意力：当解码器准备生成 “它”时，注意力机制会计算一个权重，发现此时应该高度关注输入中的 "animal"和 "tired"这些词，从而正确翻译出 “它”指代的是 “动物”。

# 现代 LLM

从传统机器学习过渡到现代 LLM 的桥梁： 2017 年发表的论文《Attention Is All You Need》,它提出了仅仅基于**注意力机制**而完全摒弃了复杂的 RNN/CNN 架构，仍采用编码器-解码器结构。

论文原文 ： https://arxiv.org/abs/1706.03762

论文中主要提出了 Transformer 架构以及 Self-Attention 自注意力机制两大创新点。
