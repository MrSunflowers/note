# vim编辑器

## 1. vi编辑器简介
vim是一个全屏幕纯文本编辑器，是vi编辑器的增强版。可以通过别名设置让输入`vi`命令时实际执行vim：
```bash
[root@localhost ~]# alias vi='vim'  # 临时生效
```
若需永久生效，需将别名配置写入环境变量文件（如`~/.bashrc`）。

## 2. vim基本使用

### 2.1 vim的工作模式
vim有三种基本工作模式：
- **命令模式**：主要使用快捷键操作，是vim的核心模式
- **输入模式**：用于文本编辑，类似记事本
- **末行模式**（编辑模式）：用于保存、退出等命令操作

#### 输入模式切换命令
| 命令 | 作用 |
|------|------|
| `a`  | 在光标所在字符后插入 |
| `A`  | 在光标所在行尾插入 |
| `i`  | 在光标所在字符前插入 |
| `I`  | 在光标所在行行首插入 |
| `o`  | 在光标下插入新行 |
| `O`  | 在光标上插入新行 |

### 2.2 命令模式操作

#### 2.2.1 移动光标
1. **基本移动**：
   - `h`/`j`/`k`/`l`：左/下/上/右（替代方向键）
   - `H`：移动到屏幕顶部
   - `M`：移动到屏幕中间
   - `L`：移动到屏幕底部

2. **文档首尾**：
   - `gg`：移动到文件头
   - `G`（Shift+g）：移动到文件尾

3. **行首行尾**：
   - `^`：移动到行首（非空白字符）
   - `$`：移动到行尾

4. **指定行跳转**：
   - `:n`：跳转到第n行（n为数字）
   - `:set nu`：显示行号（临时生效）

#### 2.2.2 删除与剪切
| 命令 | 作用 |
|------|------|
| `x` | 删除光标所在字符 |
| `nx` | 删除光标后n个字符 |
| `dd` | 删除/剪切当前行 |
| `ndd` | 删除/剪切n行 |
| `:n1,n2d` | 删除n1到n2行 |

**粘贴操作**：
- `p`：粘贴到光标后
- `P`：粘贴到光标前

> **技巧**：`dG`可从光标所在行删除到文件尾，若光标在首行则清空整个文档

#### 2.2.3 复制操作
- `yy`：复制当前行
- `nyy`：复制n行
- 粘贴同样使用`p`/`P`键

#### 2.2.4 撤销操作
- `u`：撤销上一步操作（类似Ctrl+Z）
- `Ctrl+r`：反撤销（重做，类似Ctrl+Y）

#### 2.2.5 替换操作
- `r`：替换单个字符（不进入输入模式）
- `R`：连续替换字符，按ESC退出

### 2.3 末行模式常用命令
| 命令 | 作用 |
|------|------|
| `:w` | 保存文件 |
| `:w 文件名` | 另存为新文件 |
| `:q` | 退出vim |
| `:q!` | 强制退出不保存 |
| `:wq`/`:x` | 保存并退出 |
| `:!命令` | 执行系统命令（如`:!ls`查看目录） |

### 2.4 vim配置参数
末行模式输入以下命令可临时生效：

| 参数 | 作用 |
|------|------|
| `:set nu`/`:set nonu` | 显示/隐藏行号 |
| `:set hlsearch`/`:set nohlsearch` | 高亮/取消高亮搜索结果 |
| `:set ruler`/`:set noruler` | 显示/隐藏右下角状态栏 |
| `:set showmode`/`:set noshowmode` | 显示/隐藏左下角模式提示 |
| `:set list`/`:set nolist` | 显示/隐藏隐藏字符（Tab用^I表示） |

**永久配置**：创建`~/.vimrc`文件，写入配置参数，例如：
```vim
set nu          " 显示行号
set hlsearch    " 高亮搜索
set ruler       " 显示状态栏
```

### 2.5 查找与替换
#### 2.5.1 文本查找
- `/关键词`：从光标处向下查找
- `?关键词`：从光标处向上查找
- `n`：跳转到下一个匹配
- `N`：跳转到上一个匹配

#### 2.5.2 字符串替换
| 命令 | 作用 |
|------|------|
| `:1,10s/old/new/g` | 替换1-10行所有old为new |
| `:%s/old/new/g` | 替换整个文件所有old为new |
| `:s/old/new` | 替换当前行第一个old |
| `:s/old/new/g` | 替换当前行所有old |

**示例**：
- 注释1-10行：`:1,10s/^/#/g`
- 取消注释：`:1,10s/^#//g`
- 添加//注释：`:1,10s/^/\/\//g`

## 3. vim高级技巧

### 3.1 导入内容
- `:r 文件名`：在光标处插入其他文件内容
- `:r !命令`：在光标处插入命令执行结果（如`:r !date`插入当前时间）

### 3.2 多文件编辑
- `vim -o 文件1 文件2`：上下分屏
- `vim -O 文件1 文件2`：左右分屏
- **窗口切换**：`Ctrl+w` + 方向键

### 3.3 字符替换与快捷键
#### 3.3.1 字符替换
```vim
:ab mymail shenchao@163.com  " 输入mymail自动替换为邮箱
```

#### 3.3.2 自定义快捷键
```vim
:map ^P I#<ESC>  " Ctrl+P在行首添加#注释（^P需用Ctrl+V+P输入）
:map ^B ^x       " Ctrl+B删除行首字符（用于取消注释）
```

### 3.4 格式转换
Windows与Linux文件格式转换：
- `dos2unix 文件名`：将Windows格式转为Linux格式
- `unix2dos 文件名`：将Linux格式转为Windows格式
> 注：这两个命令需额外安装（如`yum install dos2unix`）

## 4. 常见问题解决
1. **中文乱码**：在`~/.vimrc`中添加`set fileencodings=utf-8,gbk`
2. **语法高亮**：`:syntax on`开启语法高亮
3. **行号显示**：`:set nu`临时显示，永久显示需写入配置文件
