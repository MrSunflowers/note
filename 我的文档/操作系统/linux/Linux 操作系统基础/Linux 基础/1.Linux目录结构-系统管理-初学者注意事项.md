# 给初学者的Linux服务器管理建议

## 一、学习Linux的注意事项

### 1. Linux严格区分大小写
Linux是严格区分大小写的，这一点和Windows不同。操作时需注意区分大小写，包括文件名、目录名、命令、命令选项及配置文件设置选项等。

### 2. Linux一切皆文件
Linux中所有内容均以文件形式保存和管理，硬件设备也是文件。设备文件保存在`/dev/`目录中，例如硬盘文件是`/dev/sd[a-p]`，光盘文件是`/dev/hdc`等。

### 3. Linux不靠扩展名区分文件类型
Windows依赖扩展名区分文件类型（如`.txt`、`.exe`），而Linux通过权限位标识确定文件类型。常见文件类型包括普通文件、目录、链接文件、块设备文件、字符设备文件等。可执行文件是被赋予执行权限的普通文件。

**需注意的特殊扩展名**（仅为方便管理员识别）：
- 压缩包：`*.gz`、`*.bz2`、`*.zip`、`*.tar.gz`、`*.tar.bz2`、`*.tgz`
- 二进制软件包：CentOS的RPM包以`.rpm`结尾
- 程序文件：Shell脚本常用`*.sh`，C语言文件用`*.c`
- 网页文件：`*.html`、`*.php`（网页服务器要求，非Linux本身要求）

### 4. Linux中所有存储设备必须挂载后才能使用
Linux存储设备需通过挂载才能使用，挂载点是已建立的空目录（类似Windows盘符）。设备文件（如`/dev/sdb`）与挂载点的连接过程称为挂载。

### 5. Windows程序不能直接在Linux中使用
Linux与Windows是不同操作系统，软件不兼容。优势是Windows病毒和木马对Linux无效；劣势是软件需单独开发Linux版本或依赖模拟器运行。部分软件提供跨平台版本（如QQ）。

## 二、服务器管理建议

### 1. 了解Linux目录结构

| 目录名                | 目录作用                                                                 |
|-----------------------|--------------------------------------------------------------------------|
| `/bin/`               | 存放系统命令，普通用户和超级用户均可执行，是`/usr/bin/`的软链接          |
| `/sbin/`              | 存放系统命令，仅超级用户可执行，是`/usr/sbin/`的软链接                   |
| `/usr/bin/`           | 存放系统命令，普通用户和超级用户均可执行                                 |
| `/usr/sbin/`          | 存放系统命令，仅超级用户可执行                                          |
| `/boot/`              | 系统启动目录，保存内核文件和启动引导程序（grub）等                       |
| `/dev/`               | 设备文件保存位置                                                         |
| `/etc/`               | 配置文件保存位置，默认安装的服务配置文件均在此（如用户信息、启动脚本）   |
| `/home/`              | 普通用户家目录，每个用户在其中有同名子目录（如`/home/user1`）            |
| `/lib/`               | 系统调用函数库保存位置，是`/usr/lib/`的软链接                            |
| `/lib64/`             | 64位函数库保存位置，是`/usr/lib64/`的软链接                              |
| `/lost+found/`        | 文件系统修复目录，意外崩溃后存放文件碎片，每个分区均有（如`/boot/lost+found`） |
| `/media/`             | 建议挂载媒体设备（软盘、光盘等）                                         |
| `/misc/`              | 建议挂载NFS服务共享目录                                                 |
| `/mnt/`               | 建议挂载额外设备（U盘、移动硬盘等），早期Linux唯一挂载目录               |
| `/opt/`               | 第三方软件保存位置，源码包可安装于此或`/usr/local/`                      |
| `/proc/`              | 虚拟文件系统，保存内核、进程、设备状态等信息（内存中，非硬盘）           |
| `/sys/`               | 虚拟文件系统，保存与内核相关的信息（内存中）                             |
| `/root/`              | root用户家目录，区别于普通用户的`/home/`                                 |
| `/run/`               | 系统运行时数据（如ssid、pid），`/var/run/`是其软链接                      |
| `/srv/`               | 服务数据目录，系统服务启动后所需数据存放位置                             |
| `/tmp/`               | 临时目录，所有用户可访问写入，建议不保存重要数据，开机清空               |
| `/usr/`               | 系统软件资源目录（UNIX Software Resource），多数软件安装于此             |
| `/usr/lib/`           | 应用程序调用的函数库保存位置                                             |
| `/usr/local/`         | 手工安装软件保存位置，建议源码包安装于此                                 |
| `/usr/share/`         | 应用程序资源文件（帮助文档、字体等）                                     |
| `/usr/src/`           | 源码包保存位置，内核源码可存于`/usr/src/kernels/`                        |
| `/usr/src/kernels/`   | 内核源码保存位置                                                        |
| `/var/`               | 动态数据保存位置（缓存、日志、软件运行文件等）                           |
| `/var/www/html/`      | RPM包安装的Apache网页主目录                                             |
| `/var/lib/`           | 程序运行中需调用/改变的数据（如MySQL数据库`/var/lib/mysql/`）            |
| `/var/log/`           | 系统日志保存位置                                                       |
| `/var/run/`           | 服务PID保存位置，是`/run/`的软链接                                      |
| `/var/spool/`         | 队列数据目录（邮件、打印队列等）                                        |
| `/var/spool/mail/`    | 新收到邮件队列保存位置                                                 |
| `/var/spool/cron/`    | 系统定时任务队列保存位置                                               |

### 2. 远程服务器关机及重启注意事项

#### 2.1 重启前中止正在执行的服务
硬盘在高速数据交换时断电/重启易损坏，需先中止服务，必要时断开网络。个人计算机强制关机风险低是因为访问量小，服务器需严格操作。

#### 2.2 选用安全重启命令
建议使用 `shutdown -r now` 命令，可正常保存和中止程序。重启前执行几次 `sync` 命令（数据同步，将内存数据写入硬盘）。

### 3. 避免在访问高峰运行高负载命令
- **高负载命令**：复制大量数据、压缩/解压缩大文件、大范围硬盘搜索等。
- **访问高峰期**：通常为17:00-24:00，具体因服务而异（如面向美国用户需考虑时差）。
- **建议执行时间**：凌晨4:00-5:00，可通过计划任务自动执行。

### 4. 远程配置防火墙时避免锁定自己
- **风险**：误配置可能过滤自身SSH连接，导致无法登录。
- **防范措施**：
  - 本地测试防火墙规则后再上传至远程服务器。
  - 远程配置时，先设置定时任务（如每5分钟清空防火墙规则），测试无误后删除。

### 5. 指定合理密码规范并定期更新
遵循**复杂性、易记忆性、时效性**三原则，定期更换密码。

### 6. 合理分配权限
遵循**最小权限原则**，仅给予用户完成任务必需的权限。

### 7. 定期备份重要数据和日志
遵循**备份三原则**：异地备份、定期备份、多介质备份（不要把鸡蛋放在同一个篮子里）。
